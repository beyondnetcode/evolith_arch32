## Propósito

El Scorecard Ejecutivo SDLC es el panel de control de una página para liderazgo sobre una iniciativa, producto o release basado en Evolith. Resume readiness por fase, evidencia de artefactos, ownership RACI, gates de calidad, riesgos, decisiones y estado go/no-go.

## Reglas de Autoría

- Usa el scorecard para releases con visibilidad ejecutiva, exposición a cliente, impacto productivo, regulación o múltiples equipos.
- Resume evidencia fuente con links; no dupliques evidencia no controlada.
- El estado global debe seguir la peor dimensión crítica, no un promedio simple.
- Producción Activa no puede marcarse como Lista si falta evidencia de rollback u observabilidad.
