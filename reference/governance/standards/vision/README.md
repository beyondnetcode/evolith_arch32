# Vision, Maturity, and Gaps Hub

> **Bilingual Navigation:** [Versión en Español](./README.es.md)

This hub is the canonical entry point for maturity reports, architecture audit outputs, gap tracking, opportunity backlog, and supporting evidence. Readers should arrive here from the root README before opening individual reports.

## Review Order

Use this sequence during routine governance review:

| Step | Document | Purpose |
|---|---|---|
| 1 | [Executive Governance Summary](./executive-summary.md) | Start with the generated strategic signal: where to attack, current biggest problem, and blockers. |
| 2 | [Gap Tracking Board](./gap-tracking.md) | Open the ordered backlog of gaps and opportunities; status and priority are authoritative only here. |
| 3 | [Gap Reference Catalog](./gap-reference-catalog.md) | Read the detailed problem, evidence, closure criteria, and references for each `GT-*` item. |
| 4 | [Maturity Assessment](./maturity-assessment.md) | Review the consolidated TOGAF ACMM, WAF, pattern, anti-pattern, and vision-alignment assessment. |
| 5 | [Gap Closure Evidence Standard](./gap-closure-evidence-standard.md) | Confirm the evidence required before any gap can move to a closed state. |
| 6 | [Documentation Coverage Report](../../../../COVERAGE_REPORT.md) | Check bilingual and documentation coverage output generated by the harness. |
| 7 | [Current Repository Taxonomy Map](./repository-taxonomy-map.md) | Confirm where each artifact family belongs and how critical each repository area is. |
