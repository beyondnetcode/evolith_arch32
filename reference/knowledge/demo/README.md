# UMS Applied Reference Model

> Espanol: [Modelo de Referencia UMS](./ums-reference-model.es.md)

This area explains the relationship between the progressive architecture reference and its official executable product example: the open-source [User Management System (UMS)](https://github.com/beyondnetcode/ums).

UMS replaces the former local To-Do sandbox. This repository now owns reusable architectural guidance, while UMS owns runnable application code, product documentation, and current setup instructions.
