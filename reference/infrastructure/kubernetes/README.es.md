# Manifiestos Kubernetes

> **Navegación bilingüe:** [English version](./README.md)

Este directorio contiene manifiestos de Kubernetes para desplegar componentes de la aplicación de referencia.

Los manifiestos de Kubernetes se generan automáticamente a partir de los charts Helm en el directorio `../helm/`. Para despliegues de producción, usa los charts Helm directamente.
