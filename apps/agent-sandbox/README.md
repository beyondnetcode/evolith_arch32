# Evolith Agent Sandbox

This is a sandbox application demonstrating the Agentic AI topology (GT-131).
It acts as a Model Context Protocol (MCP) server that agents can connect to via Stdio.

## Usage

Agents can connect to this server by running:
```bash
node apps/agent-sandbox/index.js
```

### Tools available

- `ping`: Verify connectivity.
- `echo`: Echo messages back.
