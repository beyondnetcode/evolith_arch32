# Registro de Cambios

> **Navegación bilingüe:** [English Version](./CHANGELOG.md)

Este registro de cambios se **genera automáticamente** a partir de los mensajes
de commit que siguen [Conventional Commits](https://www.conventionalcommits.org/),
mediante `release-please`. Como los mensajes de commit del proyecto están en
inglés, el detalle por versión —con enlaces a cada commit y a las comparaciones
entre etiquetas— se mantiene en el archivo canónico:

**[CHANGELOG.md](./CHANGELOG.md)**

## Cómo leerlo

Cada versión sigue [Keep a Changelog](https://keepachangelog.com/) y agrupa los
cambios en secciones:

- **Features** — Nuevas funcionalidades.
- **Bug Fixes** — Correcciones de errores.
- **Performance / Refactor / Docs** — Mejoras internas, rendimiento y
  documentación.

## Versión actual

La última versión publicada es **1.1.0** (2026-06-16). Para el desglose completo
de cada release, consulta [CHANGELOG.md](./CHANGELOG.md).
