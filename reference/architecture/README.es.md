# Hub de Arquitectura

> Navegacion bilingue: [English](./README.md)

Esta area contiene el modelo arquitectonico reutilizable. Leela desde la politica general hasta la evidencia concreta:

| Capa | Proposito | Entrada |
|---|---|---|
| Baseline y blueprints | Definir principios agnosticos de runtime, topologia y criterios de seleccion | [Blueprints](./blueprints-es/README.md) |
| Decisiones arquitectonicas | Registrar trade-offs aceptados y su alcance | [Registro ADR](./adrs-es/README.md) |
| Descubrimiento de decisiones | Encontrar ADRs controladores por necesidad arquitectonica | [Matriz ADR](./adrs-es/adr-matrix.es.md) |
| Implementaciones por runtime | Proveer patrones de codigo regidos por ADRs especificos de runtime | [Patrones Canonicos](./canonical-patterns-es/README.md) |
| Evidencia aplicada de producto | Mostrar como un producto real adopta o especializa la referencia | [Modelo de Referencia UMS](../knowledge/demo/ums-reference-model.es.md) |

## Regla de Lectura

La linea base y los ADRs aceptados definen politica. Los perfiles de runtime y patrones canonicos definen guia de implementacion condicionada. UMS es el modelo aplicado oficial: demuestra decisiones en un producto completo, pero sus elecciones especificas de producto no se convierten automaticamente en estandares universales.
