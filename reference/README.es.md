# Hub de Referencia

Este directorio contiene el corpus de referencia arquitectónica del modelo de arquitectura progresiva.

| Área | Propósito |
|---|---|
| [getting-started/](./getting-started/README.es.md) | Rutas guiadas de lectura por rol y objetivo |
| [architecture/](./architecture/blueprints-es/README.md) | Blueprints, ADRs, topología, perfiles de stack y decisiones arquitectónicas |
| [governance/](./governance/standards-es/README.md) | Estándares de ingeniería, SDLC, onboarding y reglas de arquitectura |
| [operations/](./operations/README.es.md) | Observabilidad, soporte runtime y documentación operacional |
| [infrastructure/](./infrastructure/README.es.md) | Plataforma local, gateway, contenedores y activos de infraestructura |
| [knowledge/](./knowledge/demo/README.md) | Documentación demo, investigación, ejemplos y material de aprendizaje |

La terminología se centraliza en el [Glosario Arquitectónico](./governance/glossary.es.md). El límite entre guía reutilizable y muestra ejecutable se explica en [Demo vs Referencia](./knowledge/demo/demo-vs-reference.es.md).

Para volver a la entrada pública, usa el [README principal](../README.es.md).
