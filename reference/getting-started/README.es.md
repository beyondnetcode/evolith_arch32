# Rutas de Lectura

> Navegación bilingüe: [English](./README.es.md)

Usa esta guía cuando llegues por primera vez al repositorio y necesites una ruta corta por rol. El índice maestro sigue siendo la navegación completa; esta página es la entrada ligera.

## Elige Tu Ruta

| Rol | Empieza aquí | Luego lee | Resultado |
|---|---|---|---|
| Arquitecto | [Hub de Arquitectura](../architecture/README.es.md) | [Matriz ADR](../architecture/adrs/adr-matrix.es.md) | Entender el modelo arquitectónico y el mapa de decisiones |
| Developer | [Estándares de Ingeniería](../governance/standards/engineering/engineering-manifesto.md) | [Modelo de Referencia UMS](../knowledge/demo/ums-reference-model.es.md) | Saber qué es universal y cómo aparece en un producto empresarial |
| SRE / DevOps | [Hub de Operaciones](../operations/README.es.md) | [Hub de Infraestructura](../infrastructure/README.es.md) | Entender runtime local y activos de observabilidad |
| Producto / Funcional | [Modelo de Referencia UMS](../knowledge/demo/ums-reference-model.es.md) | [Índice Documental UMS](https://github.com/beyondnetcode/ums/blob/main/docs/MASTER_INDEX.md) | Entender el alcance del producto aplicado y su documentación |
| Contribuidor IA | [Estándares AI-Augmented](../governance/standards/ai-augmented/README.es.md) | [AGENTS.md](../../AGENTS.es.md) | Entender reglas de agentes y arquitectura IA opcional |

## Primera Sesión Recomendada

1. Lee el [README principal](../../README.es.md).
2. Abre el [Índice Maestro Global](../../MASTER_INDEX.es.md).
3. Lee el [Glosario](../governance/glossary.es.md).
4. Usa la ruta por rol anterior.
5. Valida decisiones con la [Matriz ADR](../architecture/adrs/adr-matrix.es.md).
