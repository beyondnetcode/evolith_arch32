# Mapa de Interesados

Dado que este es un Template de Arquitectura de Referencia, los interesados principales son **Consumidores Técnicos Internos** interesados en la calidad de entrega y el scaffolding estandarizado.

| Rol | Interés Principal | Métrica Primaria |
| :--- | :--- | :--- |
| **Arquitectos de Software** | Integridad estructural, aislamiento hexagonal, pureza del dominio limpio. | Índices de acoplamiento y cohesión |
| **Desarrolladores Líderes** | Reusabilidad de generadores de módulos y boilerplate de infraestructura. | Velocidad de incorporación |
| **Ingenieros DevOps** | Predictibilidad de los gates de CI, configuración de contenedores y observabilidad. | Tiempo Medio de Reparación (MTTR) |
| **Ingenieros QA** | Pirámide de pruebas limpia y verificable (Unit vs Pact). | Porcentaje de cobertura de código |
