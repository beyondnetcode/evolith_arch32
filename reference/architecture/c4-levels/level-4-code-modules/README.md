## 1. Code Level Overview

The Level 4 (Code) view maps the logical components down to their physical implementation in the repository. It specifies exactly which packages, folders, and key files correspond to the architecture blocks.

Because the codebase evolves rapidly, this view focuses on stable domain boundaries, schemas, and OPA rulesets rather than volatile implementation classes.
