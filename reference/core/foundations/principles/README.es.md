# Evolith Core — Principios Arquitectónicos

> **Navegación bilingüe:** [English version](./README.md)

**Clasificación:** Core Architecture Principles  
**Propietario:** Evolith Architecture Board

Esta área contiene principios arquitectónicos universales y neutrales respecto de proveedores que aplican a todos los productos Evolith e implementaciones satélite.

## Destinos Actuales de Migración

- Modelo de abstracción de proveedores y plugins
- Principios de Anti-Corruption Layer
- Principios de integridad y linaje de evidencias
- Responsabilidad humana y límites de agentes
- Aislamiento por tenant y neutralidad de proveedores

## Límite

Un principio Core debe seguir siendo válido aunque se reemplace cualquier producto, proveedor, modelo o herramienta nombrada. Los detalles de implementación pertenecen a `reference/products/`; las tecnologías nombradas pertenecen a `reference/platforms/`.
