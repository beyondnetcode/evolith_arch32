> **Document Type:** Implementation Gap Analysis
> **Status:** Draft — Pending Interactive Prompts Implementation

## 1. Executive Summary

This document tracks the gap between **what Evolith Core defines** (rulesets, phase gates, architecture patterns, governance rules) and **what the CLI actually executes**. The goal is to ensure 100% parity between Core definitions and CLI behavior.

### Status Overview

| Area | Coverage | Gaps | Priority |
|------|----------|------|----------|
| Phase Gates | 45% | 5 gates incomplete | P0 |
| Architecture Rules (F1/F2/F3) | 60% | Validation partial | P1 |
| Rulesets (ACL, ADRs, etc.) | 50% | CLI ignores most rules | P1 |
| Interactive Prompts | 30% | Most commands lack prompts | P0 |
| MCP Tools | 70% | 11 tools, some incomplete | P2 |

### 6.2 Required Interactive Flows

#### Flow 1: `smart-cli init` Enhanced
```typescript
const initFlow = await p.group({
  name: () => p.text({ message: 'Repository name:' }),
  type: () => p.select({ options: ['enterprise-application', 'microservice', 'library'] }),
  coreVersion: () => p.text({
    message: 'Evolith Core version (semver):',
    placeholder: '1.0.0',
    validate: (v) => /^\d+\.\d+\.\d+/.test(v) ? undefined : 'Invalid semver'
  }),
  agents: () => p.multiselect({ options: ['bmad', 'architecture', 'qa', 'sdlc'] }),
  features: () => p.multiselect({ options: ['bilingual', 'adr', 'hooks', 'acl'] }),
  phaseArtifacts: () => p.confirm({ message: 'Generate phase gate artifact templates?' }),
  adrSelection: () => p.multiselect({ options: ['ADR-0002', 'ADR-0018', 'ADR-0032', 'ADR-0040', 'ADR-0050'] })
});
```

#### Flow 2: `smart-cli sdlc handoff` Interactive
```typescript
const handoffFlow = await p.group({
  fromPhase: () => p.select({
    message: 'Current phase:',
    options: [
      { value: 'phase-0', label: 'Phase 0 - Foundation' },
      { value: 'phase-1', label: 'Phase 1 - Structure' },
      { value: 'phase-2', label: 'Phase 2 - Governance' },
      { value: 'phase-3', label: 'Phase 3 - Architecture' },
      { value: 'phase-4', label: 'Phase 4 - Production' }
    ]
  }),
  toPhase: () => p.select({
    message: 'Target phase:',
    options: /* filtered based on fromPhase */
  }),
  validateGates: () => p.confirm({ message: 'Validate phase gate requirements before handoff?' }),
  uploadEvidence: () => p.confirm({ message: 'Upload mandatory evidence artifacts?' }),
  requestWaiver: () => p.confirm({ message: 'Request waiver for any blocking criteria?' })
});
```

#### Flow 3: `smart-cli validate` Fix Flow
```typescript
const validateFlow = await p.group({
  autoFix: () => p.confirm({ message: 'Auto-fix solvable issues?' }),

    message: 'Focus validation on:',
    options: ['all', 'acl', 'open-core', 'inheritance', 'adr-0002', 'adr-0018', 'adr-0032']
  }),
  reportFormat: () => p.select({
    message: 'Report format:',
```
