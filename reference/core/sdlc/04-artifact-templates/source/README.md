# Artifact Template Sources

This directory contains reusable Markdown source files for Evolith SDLC artifacts.

Use these files when you need to copy the canonical Markdown structure into a product repository, customer delivery repository, or release workspace.

For rendered examples, use the sibling [`examples`](../examples/README.md) directory.
