# Artifact Template Examples

This directory contains rendered examples for Evolith SDLC artifacts.

Use these files to understand the expected depth, tone, and level of evidence for each artifact before authoring your own version from the source templates.

For reusable Markdown source, use the sibling [`source`](../source/README.md) directory.
