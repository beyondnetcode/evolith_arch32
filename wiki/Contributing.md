## The BMAD Method

We use the **BMAD Method** (Specification-driven AI-Driven Development). You do not have to code alone — invoke our specialized AI agents:

- **Winston (Principal Architect)**: Architectural audits and gap tracking
- **Architect Agent**: Data Mesh contracts, Event-Driven patterns, ADRs
- **Developer Agent**: Secure patterns (OWASP), progressive architecture
- **QA Agent**: Contract testing, Rego policy validation
- **DevOps Agent**: Distributed deployments, GitHub Actions
- **Docs Agent**: Translation, markdown validations

## Pull Request Process

1. **Branching**: Follow ADR-0050 (gitflow). Prefix: `feature/`, `docs/`, `fix/`
2. **ADR Updates**: Architectural changes require ADR updates
3. **Commits**: Use [Conventional Commits](https://www.conventionalcommits.org/) (`feat:`, `docs:`, `fix:`)
4. **Review**: All PRs require review + automated CI validation
