# Glosario de Términos (Lenguaje Ubicuo)

| Término | Definición |
| :--- | :--- |
| **Usuario** | La identidad autenticada que posee un catálogo personal de tareas. |
| **Tarea** | La unidad atómica de trabajo. Contiene una descripción y un estado. |
| **Estado** | La progresión actual de una tarea (ej. `PENDING`, `COMPLETED`). |
| **Propietario** | El concepto lógico que vincula una Tarea exclusivamente al Usuario que la creó. |
| **Categoría** | Un contenedor de clasificación para agrupar tareas relacionadas (ej. Trabajo, Personal). |
| **Etiqueta** | Una etiqueta granular y reutilizable que puede asociarse a múltiples tareas para filtrado cruzado. |
