# Product

> Product-specific documentation: suite, roadmap, designs, strategy, operations.

This directory contains documentation about specific products, not inherited standards.

## Structure

| Area | Path | Content |
|------|------|---------|
| **Suite** | `suite/` | Product suite vision, strategy, positioning |
| **Products** | `products/` | Per-product designs, inventories, technical specs |
| **Designs** | `designs/` | Product design documents |
| **Strategy** | `strategy/` | Product strategy, roadmap |
| **Roadmap** | `roadmap/` | Release roadmap, milestones |
| **Infra** | `infra/` | Product-specific infrastructure (Helm, Docker, K8s) |
| **Operations** | `operations/` | Product-specific operations (incidents, alerts, SLO) |
| **Releases** | `releases/` | Release notes, changelogs |
| **Research** | `research/` | Research, PoC, experiments |
| **Evidence** | `evidence/` | Applied evidence, UMS reference, demos |

## Classification Rules

- Product-specific content goes here.
- Normative, reusable standards go to `reference/core/`.
- Executable governance code goes to `src/rulesets/`.
