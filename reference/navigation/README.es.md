# Hub de Navegación Evolith

> **Navegación bilingüe:** [English](./README.md)  
> **Portal raíz:** [README](../../README.es.md)

Este directorio centraliza los documentos de navegación de nivel repositorio que antes vivían en la raíz.

Mantenerlos aquí reduce el ruido en la raíz y preserva la experiencia de usuario mediante stubs de compatibilidad en las rutas raíz antiguas.

## Meta y Objetivos

> **Meta:** ofrecer un único lugar autoritativo para todas las superficies de navegación del repositorio, de modo que el lector siempre sepa dónde mirar a continuación.

**Objetivos:**

- Mantener el Índice Maestro Global como la única superficie de navegación completa del repositorio.
- Hacer seguimiento de los releases documentales y de la cobertura bilingüe EN/ES desde el mismo hub.
- Preservar los enlaces raíz heredados mediante stubs de compatibilidad ligeros.

## Documentos

| Documento | Descripción | Objetivo / Meta | Tipo | Obligatorio |
|---|---|---|---|---|
| [Índice Maestro](./MASTER_INDEX.es.md) | Índice completo de navegación del repositorio por intención, rol y dominio | Localizar cualquier artefacto rápidamente | Índice de navegación | Sí |
| [Índice Bilingüe](./BILINGUAL_INDEX.es.md) | Estado autogenerado del emparejamiento EN/ES de cada documento de referencia | Auditar cobertura bilingüe | Índice autogenerado | No |
| [Registro de Versiones de Documentación](./DOCUMENTATION_VERSIONS.es.md) | Historial y política de releases documentales | Trazar releases documentales | Registro de versiones | No |
