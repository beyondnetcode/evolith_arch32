# Architecture Hub

> Bilingual navigation: [Espanol](./README.es.md)

This area contains the reusable architecture model. Read it from general policy to concrete evidence:

| Layer | Purpose | Entry point |
|---|---|---|
| Baseline and blueprints | Define runtime-agnostic principles, topology, and selection criteria | [Blueprints](./blueprints/README.md) |
| Architectural decisions | Record accepted trade-offs and scope | [ADR Registry](./adrs/README.md) |
| Decision discovery | Find controlling ADRs by architectural concern | [ADR Matrix](./adrs/adr-matrix.md) |
| Runtime implementations | Provide code patterns governed by runtime-specific ADRs | [Canonical Patterns](./canonical-patterns/README.md) |
| Applied product evidence | Show how a real product adopts or specializes the reference | [UMS Reference Model](../knowledge/demo/ums-reference-model.md) |

## Reading Rule

The baseline and accepted ADRs define policy. Runtime profiles and canonical patterns define conditioned implementation guidance. UMS is the official applied reference model: it demonstrates decisions in a complete product, but its product-specific choices are not automatically universal standards.
